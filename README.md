# Auralis - Wearable System

A multimodal wearable research project integrating physiological sensors,
embedded systems, and machine learning to study stress-associated
physiological patterns.

## Project Status
Under development.

## Main Components
- Hardware: CAD, PCB, FEA, sensors, and bill of materials
- Firmware: ESP32 and sensor integration
- Software: Data processing, ML, backend, and dashboard
- Research: Literature review and methodology
- Testing: Hardware, software, and validation
- Documentation: Technical documents and reports
- Competitions: Vishwakarma and Synofura deliverables

## Disclaimer
Auralis is a research prototype, not a clinically validated diagnostic device.
