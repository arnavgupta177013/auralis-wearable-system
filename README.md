# Auralis — Wearable Physiological Monitoring System

A research-oriented wearable platform exploring physiological sensors,
embedded systems, and machine learning for stress-associated patterns.

## Project Status
Under development. CAD, PCB, firmware, and machine-learning components
may be at different stages of completion.

## Repository Structure
- hardware/ — CAD, FEA, PCB, sensors, and bill of materials
- firmware/ — ESP32 firmware and sensor drivers
- software/ — Data processing, machine learning, backend, and dashboard
- research/ — Literature review and methodology
- testing/ — Hardware, software, and validation
- documentation/ — Technical documents and progress reports
- competitions/ — Competition materials
- assets/ — Diagrams and project images

## Research Disclaimer
Auralis is an experimental research prototype, not a clinically validated
device for diagnosing anxiety or panic attacks.

## Ethics and Data Protection
Human-participant studies will only proceed after required approvals.
Do not commit identifiable participant data, confidential clinical
documents, passwords, or API keys.
