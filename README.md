# Auralis - Wearable System

Multimodal physiological monitoring research project integrating
wearable sensors, embedded systems, and machine learning.

## Project Status
Under development.

## Main Directories
- hardware: CAD, PCB, FEA, sensors, and BOM
- firmware: ESP32 and sensor integration
- software: ML, data processing, backend, and dashboard
- research: Literature and methodology
- testing: Hardware, software, and validation
- documentation: Technical documents and reports
- competitions: Competition deliverables
- assets: Diagrams and project images
